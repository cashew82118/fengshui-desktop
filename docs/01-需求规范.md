# 01 需求规范 · 桌面风水分析器

> 版本 v1.0 ｜ 定稿 2026-10-24 ｜ 状态：已确认
> 上位文件：本文件是功能范围与验收标准的唯一依据。与其他文件冲突时，以本文件为准。

## 1. 一句话定义

读取 Windows 桌面图标的真实位置与名称，按中国传统风水（形势派为主、五行生克为辅）分析桌面布局的吉凶，输出可视化的九宫盘与可执行的整改建议。**全离线运行**。

## 2. 定位与边界

- **档位**：半严肃。每条诊断必须同时给出四件事：**现象 → 数据依据 → 风水原理 → 整改建议**。缺任何一项，该条诊断视为不合格。
- **不是**：算命软件。不涉及生辰八字、不排流年飞星、不对用户本人下吉凶断语（不对"你今年会不会发财"作判断，只对"桌面这个局"作判断）。
- **禁止**恐吓式文案（"大凶""血光""破财"这类），文案规范见 `03-设计规范.md`。

## 3. 核心概念定义

| 术语 | 本项目中的确切含义 |
|---|---|
| 盘 | 桌面图标列表控件的客户区矩形，作为一张"伏案案台" |
| 九宫 | 把盘按横纵各三等分，切成 3×3 = 9 格 |
| 方位映射 | 默认**坐北朝南**：上=离(南)、下=坎(北)、左=震(东)、右=兑(西)、左上=巽(东南)、右上=坤(西南)、左下=艮(东北)、右下=乾(西北)、正中=中宫 |
| 四象 | 左青龙、右白虎、前朱雀(盘之上方，即明堂)、后玄武(盘之下方，即坐方) |
| 生入 | 图标五行 **生** 宫位五行 → 吉 |
| 比和 | 图标五行 **同** 宫位五行 → 平 |
| 克入 | 图标五行 **克** 宫位五行 → 凶 |
| 泄气 | 宫位五行 **生** 图标五行 → 减分（主宫之气外流） |
| 明堂 | 离宫（上方中间格），宜开阔、宜虚 |
| 中宫 | 正中一格，宜空 |
| 空宫 | 某宫图标数为 0 |
| 杂物煞 | 无主文件（"新建 文本文档"类）、陈旧安装包、超长命名的素材包 |
| 穿心 | 图标在同一水平线或垂直线上密集连排，横贯中宫 |

### 3.1 方位可调规则

- 默认按**坐北朝南**出结果，不询问用户。
- 界面提供"实际朝向"下拉（八方位）。切换后：**八卦盘（离坎震兑巽坤艮乾的位置与五行）整体旋转**；**青龙白虎始终固定于左右**，不随盘转（四象跟人，八卦跟方位，两套体系不混）。
- 朝向只影响"宫位五行"的归属，不影响图标归类与坐标。

## 4. 五行归类规则（权威表）

归类按以下**优先级**逐级判定，命中即停：

1. **系统项白名单**（固定归属，不参与语义判断）
   - 此电脑 / 网络 / 控制面板 → **金**（器物、管理）
   - **用户档案根目录** → **金**（器物、管理；它是入口不是内容）
     · 实例：桌面显示名形如「用户名 -」，实指 C:/Users/<用户名>
     · 特征：Shell 特殊文件夹，在两个桌面目录里都没有对应文件，`kind=virtual`
   - 回收站 → **土**（承载纳垢）
2. **安装包判定** → **土**
   - `.exe` / `.msi` 且名称命中 `setup / installer / install / whql / dch / -windows.exe / _x64 / amd64 / win10 / win11`
   - **必须先于语义词典**：`android-studio-quail3-windows.exe`（1.5GB 安装包）若走语义，
     会被 "studio" 判成文思之木；但它是"器未成形"，按形法属土。此条为 2026-10-24 修正。
3. **文件夹** → **土**（承载之器，不论里面装什么）
4. **软件名录**（`app/software.py`，约 480 条具体软件名）—— 命中即按其所属五行
   - 匹配规则见 `02-技术方案.md` 2.8：**最长关键词优先 + 词边界**，防假阳性与短词抢命中
   - 排在语义词典之前：具体软件名比泛泛的词更可信（`小黑盒加速器` 应属水，不该被"小黑盒"抢去火）
5. **语义词典**（按名称关键词覆盖）—— 见 4.2
6. **扩展名**（基础归属）—— 见 4.1
7. **兜底** → **金**（未能判断时归金，并在界面上标明来源为"兜底"）

### 4.1 扩展名基础表

| 五行 | 扩展名 / 形态 | 道理 |
|---|---|---|
| 木 | doc docx txt md pdf xlsx csv pptx py js json html | 文书、代码，主生发 |
| 火 | mp4 mkv avi mov jpg png gif psd mp3 flac wav | 影音图像，主显象 |
| 土 | 文件夹、zip rar 7z、安装包（.exe 且体积大/名称含 installer setup whql x64 等） | 堆积、未消化 |
| 金 | .lnk（默认）、.exe（应用类）、驱动、硬件工具 | 器物、决断 |
| 水 | .url 链接、浏览器、下载器 | 流动、通达 |

### 4.2 语义词典（覆盖扩展名）

| 关键词 | 五行 | 说明 |
|---|---|---|
| 加速器 / 加速 / VPN / 代理 / Clash / Frp / 梯 | 水 | 通关流动，虽为 .lnk 亦归水 |
| 云盘 / 云 / 坚果云 / 网盘 / 同步 / 下载 | 水 | 流动、聚散 |
| 浏览器 / Chrome / Edge | 水 | 通达 |
| 游戏 / 影音 / 播放器 / 剪辑 / 剪映 / Resolve / PotPlayer | 火 | 显象、耗神 |
| 笔记 / 文档 / 稿 / 代码 / Code / Studio | 木 | 文思生长 |
| 驱动 / 管理器 / 控制 / 工具 / 助手 | 金 | 器物 |

> 词典与扩展名冲突时**语义优先**（例：`雷神加速器.lnk` 扩展名判金、语义判水 → 取水）。

### 4.3 颜色维度（2026-10-24 调整）

- **已做**：盘上的图标方块**按五行着色**（木绿／火红／土褐／金灰／水蓝），盘下附五行色图例。
  这是"颜色为辅"的落地方式：颜色由类型推导的五行决定，方向永远一致，不会自相矛盾。
- **暂缓**：从系统图标位图提取真实主色，折算 0.85~1.15 的"视觉强度系数"。
  暂缓理由：① 需经 Shell 取图标位图，可能触发快捷方式目标解析，与"不联网"红线有潜在冲突；
  ② 该系数只影响视觉权重、进不了评分模型，收益远小于风险。
  若后续需要，单独立项实现，仍须满足：绝不改变五行归属、提取失败静默取 1.0。

## 5. 评分体系

总分 100 = **风水六项 80 分 + 顺手度 20 分**，各项从满分起扣。
（2026-10-27 改：原六项各按 15/15/15/15/20/20 计满 100，见本节末尾「口径变更」。）

| 分项 | 满分 | 判定要点 |
|---|---|---|
| 中宫 | 12 | 中宫有图标则扣，每个扣 4 分 |
| 明堂（离宫） | 12 | **8 个以内不扣**；超过后每个 1.2 分、最多扣 5 分（顶部放常用软件属正常习惯） |
| 四象左右 | 12 | **不按数量扣分**；只有左右两侧全空时扣 6 分，其余只作说明 |
| 形态 | 12 | 三项加权：对齐度 45%、周流度（占宫数）30%、中庭留白 25% |
| 杂物煞 | 16 | 无主文件 / 陈旧安装包 / 超长素材包，逐件扣（最多扣 10，见下方权重） |
| 五行生克 | 16 | 统计各宫生入/比和/克入/泄气比例 |
| **顺手度** | **20** | **不是风水项**：算鼠标行程与分类，见 5.1 |

**5.1 顺手度（2026-10-27 新增）**

起算 8 分，加最多 15、扣最多 8，最后钳到 0–20。

| 子项 | 判定 | 分值 |
|---|---|---|
| 常用在热区 | 常用物（非归档物）落在三边：顶行三格 + 左中 + 右中。八成在热区即满分 | +6 |
| 归档在冷区 | 归档物（安装包/压缩包/种子/清洁单上的）落在底行。六成即满分；没有归档物直接给满分 | +4 |
| 聚成团 | 同一宫里同 kind + 同扩展名的 ≥3 个算一块，覆盖 35% 图标即满分 | +5 |
| 中宫别堵 | 正中一格每有 1 个扣 2 分 | −5 |
| 别塞太满 | 最挤那一宫超过 12 个，每多 1 个扣 1 分 | −3 |

- **这一项不算吉凶**，只看步数与分类；界面上也不许用"气机""旺衰"这类词去说它。
- 四角算冷区（行程最长），不算热区——虽然也贴边。
- 起算值定 8 而不是 12：实测三边五格能装下大半图标，普通桌面「常用在热区」就有 0.85 的比例，起算 12 会让这 20 分恒满、失去区分度。

**口径变更记录**

| 版本 | 日期 | 变化 |
|---|---|---|
| 1 | 2026-10-24 | 六项 15/15/15/15/20/20；明堂超 4 个即扣、最多 15；四象按左右数量扣至 15 |
| 2 | 2026-10-27 | 六项压到 80；明堂放宽至 8 个、最多扣 5；四象取消数量扣分；新增顺手度 20 |

> 免得用户以为「桌面没变分数却涨了」是程序出错。

**补充观察（2026-10-24 新增，不计分，但各自出诊断）**

| 条目 | 依据 | 说明 |
|---|---|---|
| 中轴观 | 屏幕正中竖带（`cx ∈ [0.46, 0.54]`）的图标数 | 中宫是格、中轴是线，两者不同。线上有物则视线每扫必撞 |
| 重心观 | 图标质心距盘心的欧氏距离 | 超 0.1 略偏，超 0.22 为重心偏得厉害 |
| 四隅观 | 四个角格（巽／坤／艮／乾）的空缺数 | 四隅主根基退路，全空则局无四维 |
| 宫内疏密 | 各宫图标的包围盒占本宫面积的比例 | 宫中有物却只占一角，等于"屋里只在门口堆了东西" |
| 成墙与孤岛 | 列直方图；连续 3 列以上且每列 ≥5 个＝墙 | 墙则气不能穿，岛则气无所依 |
| 三才 | 按纵三分：上带（天／愿景）、中带（人／日常）、下带（地／根基） | 天重地轻＝想得多落得少；地为零＝无根 |
| 器类构成 | 文件／文件夹／系统项的比例 | 散件多＝"还没决定放哪"，不是没整理而是没归类 |
| 局之总象 | 中宫空否 × 明堂堵否 × 白虎抬头否 × 杂物有无 × 缺行 | **组合推理**：单独看任何一条都得不到的判断 |

**杂物煞权重**（2026-10-24 按用户反馈调轻）

| 理由 | 分值 |
|---|---|
| 安装包积于盘上 | 3 |
| 无主之物（临时命名：新建/副本/未命名/无标题/copy） | 3 |
| 名目冗长（>30 字） | 2 |
| 重复命名的快捷方式（" - 快捷方式"结尾） | 1 |

- **同一件杂物只取最重的一个理由，不累加**。否则一件 1.5GB 安装包会同时吃"安装包+超长名"两份扣分。
- 该项**最多扣 10 分**（原 12/20；2026-10-27 满分压到 16 后按 60% 折算）。

**五档断语**：

| 分数 | 断语 |
|---|---|
| 90–100 | 上吉 · 气局周流 |
| 75–89 | 中吉 · 小有壅滞 |
| 60–74 | 平 · 可用待理 |
| 45–59 | 小滞 · 宜作调整 |
| 0–44 | 滞 · 当移当清 |

## 7. 输出物

### 7.1 主窗口
- 左：按真实坐标等比缩放的桌面实景盘，叠九宫格，各宫按壅塞度着色，图标画为小方块。
- 右：总分（大字号）+ 五档断语 + 三张"最该动手"卡片 + 逐条诊断列表。
- 顶：朝向选择、重新扫描。

### 7.2 导出
- 单文件 HTML 报告（自包含，无外链，双击可看）。
- 本地历史记录：每次扫描存一行（时间、总分、断语、九宫各自图标数），**不存文件名**。
  右栏「历史」页签可查看：摘要（次数/最高/最低/最近）+ 分数趋势图 + 逐条明细，**只读**，
  不提供删除入口（要清空直接删 `data/history.jsonl`）。最多保留 200 条。
- **桌面快照**（2026-10-25 加）：历史页里「保存本次分析」手动存一份**完整盘面**
  （图标名/坐标/行列/五行/来源、画布与格子尺寸、朝向、分数/评级/七项/九宫计数/五行分布），
  落 `data/snapshots/snap_YYYYMMDD_HHMMSS.json`，**不存图标全路径**。上限 200 张，超出删最旧。
  下方日历窗格按月翻页，有快照的日子标主色；点日期看当天列表，点条目开一张盘面 + 七项 + 前三条诊断。
  与 history.jsonl 分工：history 每次分析自动写、只存数字供趋势；快照只在你手点时才写、存完整盘面。

## 8. 明确不做

- 不自动整理桌面、不移动图标（阶段五的"理想布局"仅出推演图，只画不动）。
- 不分析壁纸、窗口、任务栏、开始菜单。
- 不判断用户本人运势、不给择日、不看八字。
- 不做多语言（仅简体中文）。
- v1 不做多显示器精细支持（见 02-技术方案·风险 R3）。

# 第二轮需求（v2 ｜ 2026-10-24 上午，已与用户逐条确认）

> 本节优先级高于上面各节中冲突的旧描述。冲突时以本节为准。

## 10.1 启动闸门

- **打开程序不做任何读取与计算。** 左侧盘中央一个「开始分析」按钮，点击后才读桌面、算分、写历史。
- 分析完成后按钮文案变「重新分析」。
- 未分析时的界面状态：分数显示 `—`；右栏各栏显示空状态提示；「导出报告」置灰（问 AI 栏内导出按钮同灰）；**不写历史记录**。
- 顶栏原「重新扫描」按钮**删除**，入口唯一化为盘上按钮。

## 10.2 右栏信息架构（四个一级选项卡）

| 选项卡 | 内容 |
|---|---|
| **断语** | 现有全部：分数、断语、七项评分条、对账、与上次对比；内部三个二级页签「分条／分图标／总评」 |
| **命主** | 生辰与性别设置、四吉四凶方位、本命文昌位、纳音五行、按命卦对当前桌面的解读 |
| **问 AI** | 导出信息文件 + 话术选择与整篇复制（见 10.7） |
| **历史** | 分数历史摘要、趋势折线（常驻顶部）、桌面快照（保存 + 日历 + 当日列表）、逐条明细 |

- 分数大数字与七项评分条**常驻在选项卡之上**，切换选项卡不消失。
- 选项卡需可扩展：以后加功能只增一项，不改结构。

## 10.3 设置（齿轮浮层）

右上角齿轮图标打开浮层，点击外部或按 Esc 关闭。内含：

- 主题（四套）、字号（四档）、动效开关 —— 从顶栏迁入。
- **五行对应表编辑**（见 10.4）。

## 10.4 五行对应表（三张，可增删改）

只开放三张表，**不做"按单个图标指定五行"**：

| 表 | 现有条数 | 例 |
|---|---|---|
| 软件名 → 五行 | 484 | `photoshop → 火` |
| 关键词 → 五行 | 语义词典 | `加速器 → 水` |
| 扩展名 → 五行 | 扩展名表 | `.xlsx → 土` |

- 修改写入 `data/rules.json`（**用户覆盖层，不改内置表**），优先级高于内置。
- 改完**立即重算**（不必重启）；提供「恢复默认」（删覆盖层）。
- 系统白名单（此电脑/回收站等）不开放编辑。

## 10.5 生辰与命主

- 输入：**出生年月日 + 性别**。存 `data/prefs.json`，仅本机，可一键清空，**不联网**。
- 推算三样（纯函数，本地计算）：
  1. **本命卦**（八宅派）：定四吉方（生气/天医/延年/伏位）与四凶方。**按立春分年**，男逆女顺。
  2. **本命文昌位**：按出生年干。甲巳(巽) 乙午(离) 丙戊申(坤) 丁己酉(兑) 庚亥(乾) 辛子(坎) 壬寅(艮) 癸卯(震)。
  3. **年命纳音五行**。
- 用法（用户选定方案 C）：**总分不变**，命主信息只做展示；个性化只体现在「优先文昌」的落点。
- 未填生辰时：命主栏显示填写引导；不报错、不影响其它栏。

## 10.6 推演五档

`现状 ｜ 最小调整 ｜ 全部重排 ｜ 优先文昌 ｜ 优先财库`

| 档位 | 落点 | 搬什么 |
|---|---|---|
| 优先文昌 | 巽宫；**若已填生辰则用本命文昌位** | 文书、笔记、学习类；且先把非文书清出该宫 |
| 优先财库 | **乾宫** | 工具、管理、生产力类 |

- 这两档为目标导向，**允许牺牲就近与顺手**，移动量必然大于「最小调整」。
- 界面必须同时给出：移动清单、移动数量、前后分数。不许只给一个好看的分数。

## 10.7 导出给 AI

### 导出物

单文件 Markdown，落在 `exports/AI问询_YYYYMMDD_HHMM.md`，约 6–8 KB：

| 区块 | 内容 |
|---|---|
| 头部 | 导出时间、生成程序、**隐私提醒**（含生辰与文件名，勿公开） |
| 命主 | 出生年月日、性别、命卦、四吉四凶方位、本命文昌位、纳音五行（未填则注明缺失） |
| 桌面概况 | 画布尺寸、图标总数、九宫分布、五行分布 |
| 图标明细 | 名称（可关）、五行、所在宫位、类型 |
| 当前评分 | 总分、七项得分、对账、断语 |
| 全部诊断 | 每条的现象 / 理 / 改 |
| 推演 | 最小调整与两档优先的落点、移动清单 |
| **规则说明** | 七项怎么算、九宫方位映射表、五行归属表 —— **避免 AI 自造风水量表** |

### 隐私开关

- **图标名称默认不含**；勾选「包含文件名」才写入。
- 不含时替换为 `图标01`…，只保留五行与宫位。

### 话术结构（不是若干独立句子）

每一套话术是**整篇可直接粘贴**的成品，由三部分拼成：

```
固定开头（共用）＋ 可变主体（每个功能 3 套同义）＋ 固定结尾（共用）
```

- 开头：说明附件是什么 + 要求 AI 先复述命卦、本命文昌位、七项得分以证明读懂了。
- 结尾：要求引用文件里的具体数字、不确定就说不知道、不许编造历法星宿、动作要写成"把X从A宫搬到B宫"、最后三句话总结。
- 主体：按下表七个功能各写 3 套同义版本，正文见 `docs/06-AI话术库.md`。

| 功能 | 用途 |
|---|---|
| 认识我 | 第一套用，让 AI 先读懂人再看盘 |
| 今日宜忌 | 按导出日期结合命卦给当日取向 |
| 五行调候 | 命主五行 vs 桌面五行，该删该留该添 |
| 文昌学业 | 本命文昌位与四吉方的利用 |
| 财库积蓄 | 这一局的"财"落哪一宫 |
| 布局体检 | 唯一纯看七项评分与诊断的一套 |
| 审稿 | 只让 AI 挑错，用来验证它是否真读了文件 |

### 界面

「问 AI」栏自上而下：说明一行 → 功能选择（七选一）→ **整篇预览（只读）** → 「换一版」（循环同义主体）/「复制整篇」/「导出并复制」→ 选项（☐含文件名 ☐含完整诊断）→ 补充背景输入框（可留空）→ 上次导出路径 + 打开文件夹。

- 未填生辰时：认识我、五行调候、文昌学业、财库积蓄 四套标注「需先填生辰」并禁用；今日宜忌、布局体检、审稿照常可用。
- 未分析时：整栏禁用并提示「先点左侧开始分析」。

## 10.8 明确的边界（本轮）

- 不接任何运势 API，不联网，不申请翻译 key（上一轮讨论过的星运模块已取消）。
- 不做"按单个图标指定五行"。
- 命主信息**不参与总分**，不改七项权重。
- 不做完整八字（不需时辰），不做流年飞星表。
