## 2. 评分：兼顾实用性

用户原话：「屏幕顶部图标多是合理的，我就喜欢顶上放点，方便使用。可你却说明堂被压。」

### 2.1 总分结构调整（方案 1+2 并行）

总分仍是 **100**，六项风水项 **等比压到 80**，新增「顺手度」**20**：

| 项 | 原满分 | 新满分 |
|---|---|---|
| 中宫 | 15 | 12 |
| 明堂 | 15 | 12 |
| 四象 | 15 | 12 |
| 形态 | 15 | 12 |
| 杂物 | 20 | 16 |
| 生克 | 20 | 16 |
| **顺手度** | — | **20** |

### 2.2 顺手度算法（满分 20，起算 12，加减后钳到 0–20）

| 子项 | 判定 | 上限 |
|---|---|---|
| 常用在热区 | 顶部一行 + 左侧一列 + 右侧一列放常用软件（快捷方式/浏览器/IM/办公/工具） | +6 |
| 归档在冷区 | 底部一行 + 四个角放安装包、压缩包、旧文档、截图这类归档物 | +4 |
| 聚成团 | 同类别 3 个以上相邻成块，而不是散成满天星 | +5 |
| 中宫别堵 | 正中一格堆图标（挡视线、易误触） | −5 |
| 别塞太满 | 图标总数与可用面积比，太满视觉负担重 | −3 |

**热区定义（三边）**：顶部一行、左侧一列、右侧一列。
**冷区定义**：底部一行（除四角）、四个角。

> 这套是**经验规则，不是科学结论**。它的唯一目的是别再把手顺的摆法判成错。
> 文档里必须写清这一点，界面上不给「科学」暗示。

### 2.3 老规则放宽

  青龙白虎按传统只留「宜动/宜静」的说明，不参与扣分。
- 以上两项压分后的新满分见 2.1。

### 2.4 评分口径变更的历史处理

## 3. 分图标（断语 → 分图标）

### 3.1 位置与交互

- 二级页签变成 `分条 ｜ 分图标 ｜ 总评`（分图标插在中间）
- **默认全折叠**，只露九个宫位，每行一句摘要：`中宫 · 3 个 · 平均 72`
- 点开某宫 → 列出该宫图标，一行一个：`微信 · 水 · 泄气，不宜久留`
- 再点某个图标 → 展开三段（现象 / 理 / 改法），再点收起
- HTML 报告里加同一节，用 `<details>` 实现折叠（保持离线、无 JS）

### 3.2 文案规模（定稿）

- 主句：**5 五行 × 9 宫位 = 45 种**，每种 **5 条**同义说法 = **225 条**
- 类别尾巴：5 条（安装包归档物 / 旧文档 / 截图 / 常用软件 / 文件夹）
- 判断依据复用 `fengshui.relation()`，**不新造一套口径**，免得和「生克」那项打架
- 抽取方式：与现有说法池一致，**每次分析随机抽一条**
- 单条长度按用户既定标准 **20–30 字**

> 用户最初算的是 450 种；实际 5×9=45。已当面纠正并确认。

## 4. UI 四项

| 项 | 决定 |
|---|---|
| 字体 | 正文字体**可切换**：设置 → 字体，13 个选项（黑体/宋体/新宋体/华文中宋/华文宋体/仿宋/华文仿宋/楷体/华文楷体/隶书/华文隶书/华文行楷/华文新魏），**默认黑体**，存 `prefs.json` 的 `font_family`。品牌标题、九宫卦名、总评正文、印章「風」**恒为宋体**不动。选到本机没装的字体自动退回黑体并提示。（2026-10-27 用户定稿：先试仿宋、楷体，小字发虚；最终方案是「默认黑体 + 可切」） |
| 说明块 | 左侧「现状：你桌面的真实样子…」加浅底 `sunk` + 左侧 2px 主色竖线，与背景分开 |
| 问 AI 按钮 | `复制文案 ｜ 导出数据 ｜ 导出并复制`。「导出数据」= 只落文件、不动剪贴板；「导出并复制」= 落文件 + 复制 |
| 复选框 | 含图标文件名 / 含完整诊断 改为小方框 + 淡字、**无边框无底色**，视觉上明显轻于按钮 |
| 导出报告字体字号 | 设置里加「导出报告」分组：报告字体（13 项，同界面清单）、报告字号（小/标准/大/特大）。只影响导出的 HTML，不改界面、不用重建；字号整页等比缩放，版面留白不动 |
| 使用方法 | 问 AI 页加「使用方法」按钮，弹出说明：这个功能干什么、七套话术怎么选、导出的文件喂给谁、为什么默认不写图标名 |

## 5. 阶段划分（每阶段停下等验收）

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| A | 朝向记忆 + 问 AI 三按钮 + 复选框降级 + 说明块加底 | 关掉重开朝向还在；四个按钮点着不出错；复选框一眼看出不是按钮 |
| B | 仿宋替换 + 「使用方法」弹层 | 小字不糊；四主题 × 四字号截图核对通过 |
| C | 评分改造：顺手度 20 + 六项压 80 + 放宽老规则 + 趋势图口径线 | 顶部堆图标不再被判「明堂壅塞」；分数变化解释得通 |
| D | 分图标页：225 条文案 + 两级折叠 + HTML 报告节 | 点开任意一格能看到每个图标放得对不对 |

顺序理由：A 最小最快先给到东西；B 是视觉基线，后面所有 UI 都长在仿宋上；
C 是本轮核心矛盾；D 工作量最大（225 条文案），放最后集中做。
