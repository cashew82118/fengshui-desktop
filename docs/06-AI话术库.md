# 06 AI 话术库

> 2026-10-24 确认。用于「问 AI」栏：选功能 → 预览整篇 → 复制／导出。
> 每一套话术 = **固定开头 + 主体（每功能 3 套同义）+ 固定结尾**，复制出去是可直接粘贴的整篇。
> 代码侧镜像在 `app/prompts.py`；改文案时两处一起改。

---

## 0. 固定开头（所有功能共用）

```
附件是我这份桌面与命主数据：九宫方位、每个图标的五行与所在宫、七项评分规则与我的得分、
我的命卦与四吉四凶方位，都在里面。动手之前，请先复述文件里我的命卦、本命文昌位和七项得分，
确认你读对了再往下答。
```

## 0.1 固定结尾（所有功能共用）

```
要求：结论必须引用文件里的具体数字或宫位名，不要泛泛而谈；不确定就直说不知道，
不要编造历法、星宿、流日或任何我文件里没有的信息；涉及动作的，写成
「把 X 从 A 宫搬到 B 宫」这种能直接执行的形式；最后用不超过三句话总结。
```

## 0.2 拼接与占位

- 成品 = `开头 + "\n\n" + 主体 + "\n\n" + 结尾`
- 唯一占位符：`{date}` → 导出时的本地日期（如 `2026-10-24`）
- 全文约 180–220 字，一条微信消息或一次对话框粘贴都放得下

## 1. 认识我（第一套用）

**A**
```
让我先知道自己是谁：请用一段话讲清我是什么取向的人、适合往哪个方向使劲——按八宅与纳音的
逻辑推，不要写性格测试那一套。然后对照我桌面的现状，指出哪两处是在耗我、哪一处是在助我。
```

**B**
```
把术语放一边，用我能听懂的话说：我是个什么样的人，该顺着什么性子做事？
再说我这桌面现在的样子，跟「我这个人」是合的，还是拧着的。
```

**C**
```
先给我一份自我说明书：我的命卦、纳音、四吉方分别意味着什么，落在我身上是什么倾向；
再说明我桌面现在这个样子，是在顺着这个倾向走，还是在跟它别劲。
```

## 2. 今日宜忌

**A**
```
今天是 {date}。结合我的命卦与当前桌面，给一份今日宜忌：今天适合推进什么、该避开什么、
要不要临时腾出一块桌面来做某件事。
```

**B**
```
按 {date} 这个日子，结合我的命卦说：今天该主动出击还是该守？只给我一个倾向，
不要两头都说好话。再从桌面里挑一件东西，建议我今天就用它去做一件事。
```

**C**
```
我今天要做个决定，想听你的：结合我的命卦和桌面现状，{date} 这一天适合拍板还是再等等？
给我明确的判断和一句理由。
```

## 3. 五行调候

**A**
```
文件里有我的年命纳音与桌面五行分布。请判断这张盘对我来说是「补」还是「耗」，
并按该删、该留、该添三类给清单，每条注明是哪个图标、在哪一宫。
```

**B**
```
我这几行五行里，哪一行对我最要紧、哪一行最该压？对照桌面现状给结论。
如果只能动三样东西来调我这盘的气，你动哪三样，各自补的是我缺的哪一行。
```

**C**
```
别泛泛讲五行相生相克，直接对着我的桌面说：哪些图标在助我、哪些在耗我。
按「立刻能删的」「可以留着但该挪的」「该添的」三类列给我。
```

## 4. 文昌学业

**A**
```
我的本命文昌位在文件里。请告诉我那个宫位现在放的是什么、合不合适；
再看我的生气方与延年方是空是满。如果这半年要推学业或事业，桌面最该动的是哪两处。
```

**B**
```
我接下来半年要专注做一件事（备考／写作／做项目）。结合我的本命文昌位与四吉方，
桌面该怎么摆才帮我坐得住、不被别的事拉走？给我三条具体到宫位的调整。
```

**C**
```
我的文昌位现在是空着还是有东西？如果空着，从我桌面现有的东西里挑一样搬过去，
告诉我挑哪个、为什么挑它、搬完这一格会怎样。
```

## 5. 财库积蓄

**A**
```
用我的命卦与纳音判断：我这一局的「财」该落在哪一宫（不必是通用财位）。
那一宫现在放的是什么？为了存得住，哪类东西该聚过去、哪类必须挪开？
```

**B**
```
我总存不住东西——钱、时间、精力都算。结合命卦看，我这桌面哪一处在「漏」？
给我三个堵漏的动作，每个说清动哪个宫、为什么。
```

**C**
```
如果我的「库」在文件标出的那一宫，现在放在那里的东西算入库还是散库？
该怎么换？只给三条，不要列一长串。
```

## 6. 布局体检（唯一纯看盘的一套）

**A**
```
只看七项评分与全部诊断：我最该动手的一两处在哪？给出「把哪个图标搬到哪一宫」的建议，
每条引用文件里的数字。别的东西一律不要谈。
```

**B**
```
我的总分和最低那一项文件里都有。假设我只愿意花十分钟动手，动哪一处收益最大？
只要一个动作，说清收益落在哪一项、能涨多少。
```

**C**
```
从七项里挑一项你认为给我打分不公的——分数偏低或偏高都行，说说为什么，以及你会怎么改这条规则。
```

---

## 7. 审稿（用来验证 AI 有没有真读文件）

**A**
```
先复述文件里我的命卦、本命文昌位、七项评分与我当前的七项得分，读对了再往下。
然后只做审稿：指出你不同意的判断，或这套评分模型本身的问题。不要给建议。
```

**B**
```
你觉得这套评分规则有什么毛病？哪些项的权重不合理、哪些情况会被误判？
拿我的数据当例子说，不要空谈方法论。
```

**C**
```
请指出文件里三处你认为推理不严谨的地方，并说明换成你会怎么算。
如果找不到三处，就说找到了几处，不要凑。
```

---

## 8. 使用建议（写在界面上的一行提示）

> 文件里已带评分规则，AI 不需要猜。如果它的结论里没有出现文件中的数字，多半是没读——
> 换「审稿」再试一次。

- 「今日宜忌」这类涉及日子的，AI 很容易编流日星历（九紫入中、值日星君）。
  结尾那条已经禁了，但它仍可能不听——**看到它开始报星宿，那一句就别信**。
- 「补充背景」写一句人话（比如"我做设计，素材多，桌面乱是常态"），建议会贴很多。
